# My Fedora dotfiles

Fedora Linux, niri (Wayland compositor), Noctalia shell, kitty, zsh + starship

## Not in this repo — install separately

Icons and cursors:
- papirus-icon-theme (dnf)
- Bibata-Modern-Ice cursor (download from GitHub releases, extract to ~/.local/share/icons/)

Fonts:
- JetBrains Mono Nerd Font

COPR repos needed:
- atim/starship
- che/nerd-fonts
- alternateved/keyd

Other:
- keyd remaps live in /etc/keyd/ (system folder, not home)
- wallpapers not included

## Where these files go

fastfetch/             -> ~/.config/fastfetch/
kitty/                 -> ~/.config/kitty/
niri/                  -> ~/.config/niri/
starship.toml          -> ~/.config/starship.toml
zshrc                  -> ~/.zshrc
noctalia-settings.toml -> ~/.local/state/noctalia/settings.toml

GTK and Qt theme files are generated by Noctalia's settings GUI, not stored here.
